# LogiConnect - Backend

Modular Monolith Spring Boot Application.

## Modular Domains

- `auth`: Authentication, Token verification, Passwords
- `employee`: Employee directory and profile management
- `department`: Organizational department hierarchy
- `role` / `permission`: RBAC security layer
- `chat` / `conversation` / `message`: Direct and group messaging
- `channel`: Topic and operations channels
- `announcement`: Broadcast company-wide and department notices
- `notification`: Push and in-app notifications
- `meeting` / `calendar`: Scheduling and shift coordination
- `document`: Operational documents and media attachments
- `search`: Global indexing and lookup
- `audit`: Audit trails and security logging
